# 🔒 Secure Password Generator

Hi! This is a simple but effective **Password Generator** tool written in Python.
I created this project to learn Python and Cyber Security basics.

## 🚀 Features
- Generates random and secure passwords.
- Includes letters (A-Z, a-z), numbers (0-9), and symbols (!@#$).
- User can choose the password length.
- Easy to run on Linux terminal.

## 🛠️ How to Run
1. Make sure you have Python installed.
2. Run the following command:
   ```bash
   python3 password_generator.py
